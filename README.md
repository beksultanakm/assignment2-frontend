Description

This project is about Advanced CSS using Flexbox and CSS Grid.

The website contains a navigation bar and four tasks:

Task 0 — Navigation Bar

Task 1 — Card Row

Task 2 — Page Layout with Grid Areas

Task 3 — Image Gallery

Task 4 — Portfolio Page

The project uses Flexbox and CSS Grid to create different page layouts.

Tasks

Task 0 — Navigation Bar

A navigation bar was created using Flexbox.

Logo on the left

Navigation links on the right

Equal spacing between links

Vertical alignment

Task 1 — Card Row

Three plant cards were created using Flexbox.

Each card contains:

Image

Title

Description

Button

The cards have equal height, spacing, and a hover effect.

Task 2 — Page Layout with Grid Areas

CSS Grid is used to create a page layout with:

Header

Sidebar

Main content

Footer

Grid areas are used to place each section in the correct position.

Task 3 — Image Gallery

A gallery with nine plant images was created using CSS Grid.

The gallery has:

3 columns

Equal spacing

Nine images

Hover captions

Task 4 — Portfolio Page

The portfolio page combines Flexbox and CSS Grid.

It contains:

Header

Project cards

Information section

Footer

CSS Grid is used for the main layout, while Flexbox is used inside the project cards.

Technologies

HTML5

CSS3

Flexbox

CSS Grid
